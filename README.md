# امدادگر

«امدادگر» یک وب‌اپ فارسی و قابل‌نصب برای دسترسی سریع به راهنماهای کمک‌های اولیه است. برنامه ابتدا خطرهای فوری مانند نبود هوشیاری، تنفس غیرطبیعی، انسداد شدید راه هوایی و خونریزی شدید را بررسی می‌کند و سپس راهنمای گام‌به‌گام، کارهای ممنوع و معیارهای تماس با اورژانس ۱۱۵ را نشان می‌دهد.

> **محدودیت پزشکی:** امدادگر ابزار آموزشی و پشتیبان تصمیم است؛ تشخیص پزشکی، جایگزین آموزش عملی، پزشک یا راهنمای اپراتور اورژانس نیست. محتوای پزشکی پیش از استفادهٔ سازمانی یا بالینی باید تحت حاکمیت یک پزشک یا کمیتهٔ پزشکی واجد صلاحیت بازبینی و تصویب شود.

## امکانات

- بررسی مرحله‌ای هوشیاری، تنفس، راه هوایی و خونریزی شدید
- ۲۹ راهنمای فارسی در ۸ دسته
- مرور نشانه‌محور برای یافتن **موضوعات مرتبط**، بدون ادعای تشخیص یا احتمال بیماری
- نمایش صریح نشانه‌های هشدار، اقدامات، ممنوعیت‌ها و شمارهٔ ۱۱۵
- کار آفلاین پس از بارگذاری موفق نخست
- نصب‌پذیری به‌صورت PWA روی مرورگرهای سازگار
- همگام‌سازی خودکار یا دستی پایگاه دانش
- اعتبارسنجی SHA-256 و جایگزینی اتمیک snapshot پایگاه دانش در IndexedDB
- حفظ آخرین snapshot کامل و معتبر در صورت قطع ارتباط یا نامعتبر بودن نسخهٔ دریافتی
- رابط راست‌به‌چپ، ناوبری صفحه‌کلید، وضعیت‌های `aria-pressed` و اعلان تغییر صفحه برای فناوری‌های کمکی

## اجرای محلی

پروژه وابستگی npm یا مرحلهٔ bundling ندارد. آن را از ریشه روی HTTP اجرا کنید:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

سپس `http://localhost:8080/` را باز کنید. اجرای مستقیم با `file://` برای Service Worker و IndexedDB مناسب نیست.

اعتبارسنجی و تست:

```bash
node tools/validate.mjs
node test/run-tests.mjs
```

## ساختار پروژه

```text
index.html                 پوستهٔ اصلی برنامه
css/app.css                طراحی واکنش‌گرا و دسترس‌پذیر
js/app.js                  رابط، router و مدیریت جریان کاربر
js/engine.js               تریاژ، مرتب‌سازی موضوعات و پرچم‌های هشدار
js/kb.js                   دریافت، راستی‌آزمایی و ذخیرهٔ اتمیک پایگاه دانش
js/schema.js               schema مشترک مرورگر، validator و تست‌ها
kb/symptoms.json           واژه‌نامهٔ نشانه‌ها
kb/categories.json         دسته‌بندی و نشانه‌های قابل انتخاب
kb/cases/*.json            راهنماهای مستقل کمک‌های اولیه
kb/manifest.json           نسخه، URL و SHA-256 تمام اجزای پایگاه دانش
sw.js                      ذخیرهٔ آفلاین پوستهٔ برنامه
manifest.webmanifest       تنظیمات نصب PWA با مسیرهای نسبی
tools/                     ساخت manifest، اعتبارسنجی و تولید آیکون
test/run-tests.mjs         آزمون‌های KB، موتور، PWA و یکپارچگی فایل‌ها
```

## جریان پایگاه دانش

1. در شروع، برنامه فقط snapshot محلی را می‌پذیرد که تمام شناسه‌های مورد انتظار را داشته باشد و از schema مشترک عبور کند.
2. هنگام اتصال، `kb/manifest.json` بدون استفاده از HTTP cache دریافت می‌شود.
3. فایل‌های تغییرکرده دریافت می‌شوند و SHA-256 هر فایل پیش از parse بررسی می‌شود.
4. کل snapshot شامل نشانه‌ها، دسته‌ها و همهٔ کیس‌ها پیش از نوشتن اعتبارسنجی می‌شود.
5. همهٔ رکوردها و metadata در یک تراکنش `readwrite` روی دو object store جایگزین می‌شوند؛ شکست هر بخش، تراکنش کامل را لغو می‌کند.
6. Service Worker پاسخ‌های `kb/` را cache نمی‌کند؛ مسئولیت نسخه‌بندی و یکپارچگی فقط بر عهدهٔ این خط لوله است.

## ویرایش پایگاه دانش

برای هر تغییر محتوایی:

1. فایل JSON مربوط را ویرایش کنید.
2. `version` همان کیس را افزایش دهید و `updatedAt` را به تاریخ بازبینی تغییر دهید.
3. منبع معتبر و قابل‌ردیابی را در `sources` ثبت کنید.
4. manifest را بسازید و آزمون‌ها را اجرا کنید:

```bash
node tools/build-manifest.mjs --date YYYY-MM-DD
node tools/validate.mjs
node test/run-tests.mjs
```

ساخت manifest فقط پس از اعتبارسنجی کامل انجام می‌شود. `kbVersion` به‌طور خودکار افزایش می‌یابد؛ برای انتشار کنترل‌شده می‌توان از `--version N` استفاده کرد.

## مبانی محتوای پزشکی

منابع محوری این نسخه عبارت‌اند از:

- [AHA 2025 CPR & ECC Guidelines](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines) برای BLS، خفگی، غرق‌شدگی، هایپوترمی و اوردوز اوپیوئید
- [2024 AHA and American Red Cross Guidelines for First Aid](https://cpr.heart.org/en/resuscitation-science/2024-first-aid-guidelines) برای خونریزی، سوختگی، آنافیلاکسی، گرمازدگی و سایر کمک‌های اولیه
- [WHO Snakebite](https://www.who.int/health-topics/snakebite) برای اصول کمک اولیه در گزش مار
- [WHO Rabies](https://www.who.int/news-room/fact-sheets/detail/rabies) برای مواجهه با گزش حیوان
- [World Allergy Organization Anaphylaxis Guidance](https://www.worldallergyorganizationjournal.org/article/S1939-4551(20)30375-6/fulltext) برای آنافیلاکسی
- منابع بالینی منتشرشده دربارهٔ گونه‌های مهم ایران، از جمله `Hemiscorpius lepturus`، `Androctonus crassicauda`، `Echis carinatus` و `Macrovipera lebetina`
- اطلاعات رسمی سازمان غذا و داروی ایران دربارهٔ سامانهٔ ۱۹۰ برای اطلاع‌رسانی داروها و سموم

منبع اختصاصی هر راهنما و تاریخ بازبینی آن در خود برنامه قابل مشاهده است. اختلاف بین منابع با اولویت حفظ حیات، تماس زودهنگام با ۱۱۵ و پرهیز از مداخلهٔ پرخطر مدیریت می‌شود.

## استقرار

تمام مسیرهای برنامه نسبی‌اند؛ بنابراین می‌توان آن را در ریشه یا یک زیرمسیر روی میزبان ایستا مانند GitHub Pages یا NGINX منتشر کرد. سرور باید فایل‌ها را با HTTPS و MIME type درست ارائه کند. برای فعال‌شدن نسخهٔ جدید پوسته، کاربر باید همهٔ پنجره‌های نسخهٔ قبلی را ببندد و برنامه را دوباره باز کند.
