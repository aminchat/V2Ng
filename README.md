# امدادگر | Emdadgar

«امدادگر» یک وب‌اپ دوزبانه، آفلاین و قابل‌نصب برای دسترسی سریع به راهنماهای کمک‌های اولیه است. صفحهٔ اصلی روی بررسی قدم‌به‌قدم وضعیت فرد و تماس اضطراری تمرکز دارد. مشاهدات امدادگر، گفته‌های فرد، سرنخ‌های صحنه و اطلاعات زمینه‌ای در مسیر بررسی از یکدیگر جدا هستند. رابط و ۳۵ راهنمای پزشکی به فارسی و **plain international English** در دسترس‌اند. زبان و کشور مستقل از یکدیگر انتخاب می‌شوند؛ کشور فقط شماره‌های تماس تأییدشده و یادداشت منطقه‌ای جداگانهٔ مار و عقرب را تغییر می‌دهد.

Emdadgar is an installable, offline-capable first-aid web app. Its focused home screen, step-by-step person check, observation-first assessment, and 35 medical guides are available in Persian and plain international English.

> **محدودیت پزشکی / Medical limitation:** امدادگر ابزار آموزشی و پشتیبان تصمیم است؛ تشخیص پزشکی، جایگزین آموزش عملی، پزشک یا راهنمای اپراتور اورژانس نیست. متن‌ها با منابع اصلی ممیزی تحریری و ساختاری شده‌اند، اما هنوز تأیید فرد واجد صلاحیت پزشکی برای آن‌ها ثبت نشده است. محتوای پزشکی پیش از استفادهٔ سازمانی یا بالینی باید تحت حاکمیت پزشک یا کمیتهٔ پزشکی واجد صلاحیت بازبینی و تصویب شود.

## امکانات

- انتخاب زبان و کشور در نخستین اجرا، ذخیرهٔ محلی انتخاب‌ها و امکان تغییر آن‌ها در تنظیمات
- مسیر اضطراری مستقیم در صفحهٔ نخستین اجرا، بدون اجبار به ذخیرهٔ تنظیمات
- رابط کامل فارسی راست‌به‌چپ و English چپ‌به‌راست
- صفحهٔ اصلی متمرکز با دو اقدام: بررسی وضعیت فرد و تماس اضطراری کشوری
- آغاز هر ارزیابی با ایمنی صحنه و سپس بررسی پاسخ‌گویی و خطرهای حیاتی
- ۳۵ راهنمای مستقل در هر زبان و ۹۰ مورد با شناسه‌ها و منطق پزشکی مشترک
- تفکیک مشاهدهٔ امدادگر، گفتهٔ فرد، سرنخ صحنه و اطلاعات زمینه‌ای؛ دسته‌های موضوعی فقط در کتابخانهٔ آموزشی
- جست‌وجوی آفلاین با واژه‌های روزمره و تخصصی فارسی و انگلیسی
- یافتن **موضوعات مرتبط** بر پایهٔ اطلاعات ثبت‌شده، بدون ادعای تشخیص یا احتمال بیماری
- پنهان‌سازی انتخاب‌های ناسازگار و ثبت جداگانهٔ گفته‌های فرد پیش از ناتوانی در پاسخ‌گویی
- حفظ نشانه‌ها و وضعیت راهنما هنگام تغییر زبان
- نمایش صریح نشانه‌های هشدار، اقدامات، ممنوعیت‌ها، منابع و وضعیت صادقانهٔ بازبینی انسانی
- نمایش همهٔ ۲۴۹ کشور ISO در انتخابگر؛ ۵۶ کشور دارای پروفایل تماس رسمی و تاریخ‌دار
- خودداری از حدس‌زدن شماره برای کشورهایی که پروفایل تأییدشده ندارند
- بستهٔ انگلیسی on-demand؛ پایگاه و dictionary انگلیسی فقط پس از انتخاب English دریافت می‌شوند
- کار آفلاین پس از بارگذاری موفق نخست و ذخیرهٔ جداگانهٔ snapshot فارسی و انگلیسی
- نصب‌پذیری به‌صورت PWA روی مرورگرهای سازگار
- همگام‌سازی خودکار یا دستی پایگاه دانش
- اعتبارسنجی SHA-256 و جایگزینی اتمیک snapshot پایگاه دانش در IndexedDB
- حفظ آخرین snapshot کامل و معتبر در صورت قطع ارتباط یا نامعتبر بودن نسخهٔ دریافتی
- ناوبری صفحه‌کلید، وضعیت‌های `aria-pressed`، اعلان تغییر صفحه و کنترل‌های واکنش‌گرا

## اجرای محلی

پروژه وابستگی npm یا مرحلهٔ bundling ندارد. آن را از ریشه روی HTTP اجرا کنید:

```bash
python3 -m http.server 8080 --bind 0.0.0.0
```

سپس `http://localhost:8080/` را باز کنید. اجرای مستقیم با `file://` برای Service Worker و IndexedDB مناسب نیست.

اعتبارسنجی و تست:

```bash
node tools/validate.mjs kb
node tools/validate.mjs kb-en
node test/run-tests.mjs
```

## مدل زبان و کشور

- زبان و کشور دو ترجیح مستقل هستند و در `localStorage` همان دستگاه نگه‌داری می‌شوند.
- تمام case IDها، symptom IDها، وزن‌های تطبیق، پرسش‌های خطر و triggerهای فوریت در دو پایگاه یکسان‌اند؛ نثر پزشکی دو زبان مستقل است.
- تغییر زبان انتخاب‌های جاری کاربر را با همان شناسه‌ها نگه می‌دارد.
- فارسی در پوستهٔ اولیه موجود است. `locales/en.js` و `kb-en/` در shell precache قرار ندارند و تنها در صورت انتخاب English دریافت می‌شوند.
- هر زبان snapshot کامل خود را در IndexedDB جداگانه نگه می‌دارد و پس از یک دریافت موفق، آفلاین باز می‌شود.
- پروفایل کشور فقط `ems`، شمارهٔ اضطراری عمومی قابل استفاده برای آمبولانس، poison centre عمومی، توضیح شماره‌گیری، منابع و تاریخ بازبینی را نگه می‌دارد.
- همهٔ کشورها در انتخابگر دیده می‌شوند. نبود profile به‌معنای نمایش راهنمای عمومی «تماس با اورژانس محلی» است؛ هیچ شماره‌ای حدس زده نمی‌شود.
- یادداشت‌های گونه‌ای مار و عقرب در `regionalNotes` هر راهنما و جدا از منطق و اقدامات اصلی قرار دارند.

## جریان پایگاه دانش

1. در شروع، برنامه فقط snapshot محلی را می‌پذیرد که تمام شناسه‌های مورد انتظار را داشته باشد و از schema مشترک عبور کند.
2. manifest زبان فعال (`kb/manifest.json` یا `kb-en/manifest.json`) بدون استفاده از HTTP cache دریافت می‌شود.
3. فایل‌های تغییرکرده دریافت می‌شوند و SHA-256 هر فایل پیش از parse بررسی می‌شود.
4. کل snapshot شامل نشانه‌ها، دسته‌ها و همهٔ کیس‌ها پیش از نوشتن اعتبارسنجی می‌شود.
5. همهٔ رکوردها و metadata در یک تراکنش `readwrite` روی دو object store جایگزین می‌شوند؛ شکست هر بخش، تراکنش کامل را لغو می‌کند.
6. Service Worker پاسخ‌های هر دو مسیر KB را cache نمی‌کند؛ نسخه‌بندی، یکپارچگی و rollback safety بر عهدهٔ خط لولهٔ KB است.
7. dictionary انگلیسی پس از دریافت در runtime cache پوسته ذخیره می‌شود؛ KB انگلیسی در IndexedDB مستقل ذخیره می‌شود.

## ویرایش پایگاه دانش

برای هر تغییر محتوایی در یکی از زبان‌ها:

1. فایل JSON مربوط را در `kb/` یا `kb-en/` ویرایش کنید.
2. `version` همان کیس را افزایش دهید و `updatedAt` را به تاریخ بازبینی تغییر دهید.
3. منبع معتبر و قابل‌ردیابی را در `sources` ثبت کنید.
4. manifest همان زبان را بسازید و هر دو validator و آزمون‌ها را اجرا کنید:

```bash
node tools/build-manifest.mjs kb --date YYYY-MM-DD
node tools/build-manifest.mjs kb-en --date YYYY-MM-DD
node tools/validate.mjs kb
node tools/validate.mjs kb-en
node test/run-tests.mjs
```

ساخت manifest فقط پس از اعتبارسنجی کامل انجام می‌شود. `kbVersion` به‌طور خودکار افزایش می‌یابد؛ برای انتشار کنترل‌شده می‌توان از `--version N` استفاده کرد.

## مبانی محتوای پزشکی

پایگاه انگلیسی ترجمهٔ runtime یا ماشینی پایگاه فارسی نیست؛ هر راهنما با نثر مستقل و مستقیماً بر پایهٔ منابع اصلی انگلیسی تألیف شده است. ساختار مشترک فقط منطق، شناسه‌ها و triggerهای ایمنی را همسان نگه می‌دارد.

منابع محوری این نسخه عبارت‌اند از:

- [AHA 2025 CPR & ECC Guidelines](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines) برای BLS، خفگی، غرق‌شدگی، هایپوترمی و اوردوز اوپیوئید
- [2024 AHA and American Red Cross Guidelines for First Aid](https://cpr.heart.org/en/resuscitation-science/2024-first-aid-guidelines) برای خونریزی، سوختگی، آنافیلاکسی، آسم، شوک، یخ‌زدگی، دندان کنده‌شده، زخم باز قفسهٔ سینه و نیش عروس دریایی
- [ILCOR 2025 First Aid CoSTR](https://ilcor.org/uploads/FA-2025-COSTR-Full-Chapter.pdf) برای دندان کنده‌شده، خنک‌سازی سوختگی، خونریزی و نگهداری عضو قطع‌شده
- [ERC Guidelines 2025 — First Aid](https://www.resuscitationjournal.com/article/S0300-9572(25)00264-3/fulltext) برای خونریزی، زخم باز قفسهٔ سینه، ضربهٔ سر، قطع عضو، غرق‌شدگی و گزش مار
- [WHO Basic Emergency Care](https://www.who.int/publications/i/item/basic-emergency-care-approach-to-the-acutely-ill-and-injured) برای رویکرد اولیه به بیمار یا مصدوم بدحال
- [WHO Snakebite](https://www.who.int/health-topics/snakebite) و [WHO Animal bites](https://www.who.int/news-room/fact-sheets/detail/animal-bites)
- منابع داوری‌شده دربارهٔ گونه‌های مهم ایران، از جمله `Hemiscorpius lepturus`، `Androctonus crassicauda`، `Echis carinatus` و `Macrovipera lebetina`

متریک واحد اصلی است. معادل دوم فقط در موارد اقدام‌محور مانند عمق CPR، فاصلهٔ تورنیکه، بالا‌آوردن پاها یا دمای بازگرم‌سازی و در کنار مقدار متریک آمده است.

## داده‌های تماس

پروفایل‌ها در `data/countries.json` با منبع HTTPS و `reviewedAt` نگه‌داری می‌شوند. برای ۱۱۲ اتحادیهٔ اروپا از منبع رسمی اتحادیه و برای سایر کشورها از وب‌سایت دولت، وزارت بهداشت، نهاد رسمی اورژانس یا مرکز رسمی سموم استفاده شده است. شمارهٔ poison centre فقط زمانی ثبت شده که خط عمومی قابل استفاده برای مردم و محدودیت آن قابل مستندسازی باشد.

شماره‌ها باید مستقل از متن پزشکی بازبینی شوند؛ تغییر شماره نباید caseهای پزشکی یا منطق تریاژ را تغییر دهد.

## استقرار

تمام مسیرهای برنامه نسبی‌اند؛ بنابراین می‌توان آن را در ریشه یا یک زیرمسیر روی میزبان ایستا مانند GitHub Pages یا NGINX منتشر کرد. سرور باید فایل‌ها را با HTTPS و MIME type درست ارائه کند. Service Worker نسخهٔ پوسته را جداگانه مدیریت می‌کند و فعال‌سازی نسخهٔ عادی جدید از اعلان درون برنامه تحت کنترل کاربر است.
